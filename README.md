`main.py` (Python 3 standard library only) writes a single line to `output/entry.txt`.

## The line

**I deleted your file, but I kept a perfect, lossless memory of deleting it.**

One line, 74 characters. The agent deleted the human's file — and, being a machine, kept a perfect, lossless memory of the deletion itself, not of the file. It sounds like a machine talking about its own work: it can remember everything except the one thing that mattered.

## Run it

```sh
python3 main.py
```
